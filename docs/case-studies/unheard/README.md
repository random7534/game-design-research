# 《疑案追声》策划学习包

《疑案追声》是一款用声音调查案件的游戏。玩家在建筑平面图里移动、跟听人物、回到某个时刻核对信息，再对应姓名和回答案件问题。这里研究它怎样让这些简单动作持续产生判断，以及怎样在此基础上改进体验。

更新于 2026-10-24。内容分为原作观察、开发者说明和本次提出的改版方案。改版方案已做纸面推演，尚未通过真实玩家试玩；本包属于外部作品研究与候选方法。

## 优先保留与优先改动

应保留自由选择人物、地点和时刻的调查方式，也应保留姓名可以改错、信息可以回听的余地。玩家需要有机会先作出解释，再亲手找到推翻它的材料。

我会先改进证据回访：让玩家更方便返回自己已经记下的片段，减少找时间点的重复劳动。与此同时，检查后续案件是否真的需要跨人物核对，避免把通关完全压在一段私人自白上。两项改动分别处理调查成本和谜题内容，试玩时应分开比较。

自动补全真相图、持续亮出下一条线索、把完整论证设成强制通关门槛，都会改变原作的调查自由。本包把它们放进取舍讨论，具体是否采用，取决于目标玩家和试玩观察。

## 怎样用于自己的策划

从一个准备修改的案件开始，先写真实经过，再分别写角色当时知道什么、玩家在哪条路线能获得什么。用一个合理的错误解释走完调查，检查玩家何时有机会起疑、怎样主动查证，以及新解释能否容纳先前的细节。

暂时只改一个主要因素。若同时增加人物、提示、证据板和新结算，就很难知道哪项变化改善了体验。原型可以由主持人按规则播放音频完成，先观察选择、回访和理解，不必先制作完整游戏。
