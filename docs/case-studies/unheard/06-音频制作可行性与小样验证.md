# 音频素材怎样制作：先验证角色，再扩大案件

更新于 2026-10-24。基础对白有可用的语音合成路线，常见音效也可以自行录制或从授权素材库选取。真正需要先验证的是：同一角色跨台词是否稳定，情绪变化后能否认人，多人对话能否听懂，以及声音能否可靠承载证据。本轮查了官方能力说明，尚未生成试听样片，不能承诺达到原作配音质量。

## 这个约束怎样改变魔改顺序

若先修改原作的调查工具，例如给已有笔记增加地点、对照自己保存的片段，设计上可以沿用原录音，新增角色配音需求很小。原作文件能否接入这些功能，仍需另行实现验证。

[证据质询](05-魔改方向与首个可玩片段.md)会增加对白。第一轮可以把案后问话做成文字笔录，保留案发录音的听觉调查，用来检验质询是否促使玩家回去核对。它能检查证据逻辑和选择，却不能证明全语音质询的节奏已经成立。

如果要制作完整的新案件，我更倾向于少量原创角色，统一制作整案声线。给原角色续写配音，还需要衔接原来的音色、表演和录音质感，难度高于从头建立四个新角色。有限干预会增加分支对白，应等基本声音质量和返工量明确后再扩展。

## 把音频分开估算

| 素材 | 建议做法 | 必须检查什么 |
|---|---|---|
| 角色对白 | 固定角色音色，按有上下文的对白段落生成并挑选，保留独立角色音轨 | 身份稳定、姓名读音、否定词、情绪与说话对象 |
| 门、脚步、箱子、钥匙等 | 自行录制或选取有明确授权的素材，再按动作安排 | 声音是否与动作对应，会不会盖住线索 |
| 电话、广播、隔墙声 | 从已经确认的原声制作效果版本 | 各处是否确实对应同一次事件，时间是否对齐 |
| 环境底噪 | 少量循环素材，按地点组合 | 不意外出现像人声、提示声或敲击暗号的噪声 |
| 哭笑、争吵、抢话等表演 | 先做代表样片，再决定合成、改写或用真人完成整个角色 | 表演有无说服力，变化后还能否认出角色 |

多人对话模型可以用来试听整体节奏，但不能未经核对就假设输出包含可分别移动到房间里的独立角色音轨。正式制作要保留所需的分轨；将所有人物一次混成一条声音，会妨碍自由跟听、局部修改和空间处理。

## 当前可比较的两条对白路线

以下能力按 2026-10-24 的官方资料核对，属于候选工具，未做本项目音质排名。

**云端生成后保存文件：MiniMax。** 官方同步语音接口支持中文、指定音色，以及情绪、停顿和发音控制；不同版本支持范围有差异。它适合在制作期生成台词文件，不必让玩家每次回放都重新联网合成。接口支持这些参数，不代表多人对戏、轻声和强烈情绪已达到本案要求。[官方同步语音说明](https://platform.minimax.cn/docs/api-reference/speech-t2a-http)

**下载模型本地生成：Qwen3-TTS。** 官方提供中文、批量生成、预置音色；1.7B CustomVoice 支持指令控制。还可先用 VoiceDesign 设计原创声线，再用 Base 复用该样本制作后续台词。不能把这些模型的能力视为完全相同，也不能仅凭模型规模断定本机速度和显存够用。[官方仓库与示例](https://github.com/QwenLM/Qwen3-TTS)

先用预置音色比较小样，能用就不急着设计新声线。确需原创音色时，用自己设计或获准使用的参考声音，并保存所选模型、音色来源和使用条件。实际费用、服务套餐和素材使用条件需要按最终选择确认，这里不报未经试算的整案价格。

## 推理游戏需要额外守住的声音规则

**同一事件用同一份已确认的录音。** 一个人在现场说话，另一处通过电话听到，应复用同一次表演，再制作电话效果。分别生成两份“同样的台词”，可能得到不同的停顿、语速和字音，玩家可能把差异当成剧情线索。门铃、广播等跨路线共同听到的事件也同理。

**音色固定，角色习惯也要稳定。** 可以分别设定较低且缓慢、明亮且急促、说话前有短暂停顿等特征，再比较它们在不同情绪下是否仍可区分。这些是待试听的角色设计，不能只靠给音色起三个不同名字就认为能辨认。也不宜让所有关键判断都依赖细微口音或音高。

**一句话里的表演也会透露信息。** 若所有谎话都生成得结巴、所有真话都理直气壮，玩家会从表演标签直接猜答案。人物是否紧张，应与处境、性格和具体隐瞒相符。误导要来自有依据的误解，避免用随机杂音或发音错误制造难度。

**制作期生成，确认后固定。** 游戏回放使用已经检查过的文件，避免每次重听都生成新版本。生成式对白本身存在变化；ElevenLabs 的官方多人对白说明也明确提示，使用相同随机种子仍可能有细微差别。[官方说明](https://elevenlabs.io/docs/overview/capabilities/text-to-dialogue)

**台词改动可能影响整段事件。** 重新配音若更长，可能撞上另一人的回应、电话铃或角色离开房间的时刻。可以从语气、停顿、剪辑和对白措辞调整；关键字词不能为了硬塞进旧时长而被压得听不清。需要移动事件时，要重听受影响的整段经过。

## 先做一个小样，查最危险的问题

暂定三名原创角色，每人六句，覆盖平静、轻声和急促表达，再安排一通两端可听的电话、一次开门与搬箱动作，组成约九十秒的场景。数字只是试做规模，不是已经完成的音频。这个片段只验证声音能力，不承担完整案件的证据链。

先听没有身份标签的片段，观察试听者是否能稳定区分三人；再加入电话和空间效果，检查是否仍能对应角色、听清关键字；最后比较同一通电话的两端，确认内容与时序一致。允许使用面向玩家的字幕或其他辅助方式，另记它们对辨人与推理的影响。

如果三人反复混淆，先换音色或调整角色说话习惯。若轻声总是吞掉线索，就改变表演或线索安排。若强烈情绪始终不合适，可以改写那段场面，或由真人完整承担该角色，避免同一角色普通台词与关键表演突然换声。

只有这个样片通过，才扩展到四人短案。记录每句生成尝试、挑选、修正和混音所用的工作，才能估算后续生产量。检查文字是否读对只是其中一步，自动转写不能代替人工听辨和玩家体验。

## 怎样算清素材量

案件时间长度、所有角色发言时长之和、人物经历的所有分支，是三个不同的量。六分钟案件有平行谈话，实际需要制作的独立对白可能超过六分钟；相同电话录音在两处出现，不应重复算成两段独立表演。

预算从最终剧本的台词量、独立音效和新增分支算起。保留合格片段，只重新制作修改或不合格的部分。定稿前先用低成本占位验证逻辑，再制作正式声音；但涉及辨人、听觉线索和情绪误导的疑问，必须用接近目标质量的小样验证。
