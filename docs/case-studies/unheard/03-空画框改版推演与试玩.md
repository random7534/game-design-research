# 《空画框》改版推演与试玩

状态为策划提案，尚未实现或试玩。下文界面、调查过程和人数都是暂定设计，不能当作效果记录。包含第二案剧透。

## 只改找回已有证据的操作

要验证的问题是，帮助玩家找回自己发现过的声音，能否减少机械重听，同时保留自己推理的满足。

原作已有时间弹幕、跟人、改名和回放。本提案复用这些能力，新增两个对照位：玩家从自己的已有笔记中各选一条，在同一面板交替返回两段现场，分别保留时间与聆听位置。新增差异在于同时保留两条返回状态、便于交叉核对；单条书签或一键回放不另算创新。

单条时间与地点返回，是[优化方案](02-优化方案与取舍.md)中另提的改动，不能当作原作已经具备的能力。本篇的双槽比较以两版都具备相同的单条回访为前提；单条回访相对原作是否有价值，需要另行验证。

笔记只显示玩家保存的时间、位置、手写内容及当时使用的姓名标签。玩家可自行标为待核、暂信或撤回，系统不判真、不提炼结论、不显示遗漏提示。未记录的私聊不会自动变成证据卡；同一时刻另一房间的内容也不会被补进来。找错或没保存时，仍须自由移动和回放。返回后能继续听前后文，避免把一句话裁成脱离语境的证据。

## 一次约两三分钟的调查操作串

这是代表性操作推演，不是首次通关用时承诺。假设玩家已听过麦克的行动报告、黄毛取画线路、刘总的电话、厕所相遇及保安末段报告，且本段要调用的片段均已由玩家自行保存；刚发现秘书开场私聊。若某段没有保存，必须先自由定位并记录，不能直接出现在对照位中。以下只决定如何核对已经取得的信息。

| 阶段 | 已经取得的信息 | 暂时相信什么 | 玩家操作与新获得的理解 |
|---|---|---|---|
| 初次误判 | 秘书声称早已拿到真画；刘总告诉麦克，他手中是假画 | 秘书下手更早，麦克拿错了 | 玩家原先只记了刘总的判断，没有把它标成客观鉴定 |
| 发现反证 | 秘书私聊表明自己不过手真品 | 她对刘总的说法可能有假 | 玩家主动保存这段，左槽放私聊，右槽放刘总电话；交替听，发现刘总的判断依赖秘书，缺少独立依据 |
| 选择回查对象 | 已取得麦克行动报告与黄毛路线，先后仍待核对 | 不能再沿用“麦克拿假”的起点 | 玩家可先核对麦克报告，也可先查黄毛路线。此处选择前者，再把两槽改放麦克报告与黄毛取画，交替核对，自行修正第一次交换 |
| 重算第二次交换 | 已听厕所相遇，但先前误解了两人各自持有什么 | 麦克以为自己在纠错，实际可能换走真品 | 玩家回到自己保存的厕所片段，连同前后文重听，再接保安的追拦与报告；不靠一次碰撞音单独推断全部交换 |
| 提交理解 | 三幅画的独立来路与两次交换已能相接 | 最早持有者和最终持有者可以不同 | 玩家在可选手记写下路径，仍按原题提交麦克、保安；系统不要求连满证据图，也不校验手记措辞 |

这里的已知，首先是玩家听见某人作了某种陈述，不等于陈述内容已经被证实。界面不会把刘总的说法直接改写为“麦克持有假画”，也不会在玩家反应过来之前亮出“秘书说谎”。

推演者最终复原的路径如下；这是策划说明，不是提前展示给玩家的图。A、B、C 也由调查者自行命名，界面不预填真假。

- A 真画：作品存放处 → 麦克 → 黄毛 → 保安。
- B 麦克带来的复制品：麦克 → 存放处 → 黄毛 → 麦克。
- C 秘书的仿画：秘书 → 刘总。

原作事件依据[3DM-Meteor 第二案攻略](https://www.3dmgame.com/gl/3765059_2.html)核对；三幅画应分开追踪，另参照[Steam 指南及 CHILL FOREST 更正讨论](https://steamcommunity.com/sharedfiles/filedetails/?id=2851371246)。该指南仍残留秘书偷取真画的旧叙述，不整页照收。两槽界面、上述玩家路线与判断变化均为本提案。本次综合的来源边界见 [sources.md](sources.md)。

## 最小对照试玩

待有可操作样机后，先找六名没有玩过或看过本案攻略的推理游戏玩家，暂按每版三人随机分组。同一人不重复玩同案，避免记住答案。两版使用相同剧情、声场、原有工具和操作教学，也都有相同的单条时间/地点返回、姓名标签和笔记状态选项；只有一版增加双槽。主持人不提示秘书、真假或该去哪间房。

一轮只观察四件事：找回明确想重听的旧片段花了多久、找错多少次；哪些重复播放源于定位失败，哪些是在主动验证；提交后能否解释麦克为何把真画换走，并区分两份假画；事后请玩家指出哪一步是自己想明白的、界面是否替他作了判断。不把总用时越短或重听越少直接当作成功。

若改版减少找错和无目的搜寻，玩家仍能解释路径、主动选证据、把发现归于自己的判断，才值得扩大验证。六人的结果用于发现问题和决定下一轮改动，不能声称统计显著或代表全部玩家。纸面面板可以先查操作是否看得懂，但不能证明真实回听更省时。

这一轮只能比较双槽相对单条回访的价值，不能据此声称整套回访方案优于原作。正式测试从正常调查开始，玩家是否会主动保存和使用记录也是观察结果；前面的片段齐全假设只用于演示操作，不作为试玩时强行提供全部证据的条件。

出现以下情况就应修改或撤回：面板频繁打断听声；玩家只是按左右顺序播放，不再提出问题；系统标签被当成真相；定位虽快，解释交换却更差；多数人当时没留笔记，新增功能很少有用。最后一种结果可能说明需要改善记录时机，也可能说明这一辅助不值得增加，不能立即用自动收集全部线索补救。

## 三种扩展为什么先不加

自动证据图若替玩家标出真假、关联和缺口，会把本案最重要的物品追踪交给系统。可以试验玩家手画的空白关系图，暂不提供标准图形轮廓与正确连线反馈。

强制论证会使自由监听变成按设计者格式交作业。若以后做法庭辩论，可以让举证成为玩法；本次只在试玩后的开放提问中检查理解，不增加通关手续。

整案全文字幕检索会允许按关键词跳过尚未听过的声音，削弱声线、位置和人物关系的作用。字幕和语言辅助仍有无障碍价值，可另设清楚说明的辅助方式；不要默认开放全部未发现剧情，再把搜索答案称为本次找回旧证据的改进。
