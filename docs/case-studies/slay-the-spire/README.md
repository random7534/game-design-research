# 《杀戮尖塔》一代设计研究

更新于2026-10-25。《杀戮尖塔》一代把单人爬塔与牌组构筑结合起来：玩家打怪、选牌、取得遗物、决定路线，在不断变化的条件下推进一局。本页研究公开信息怎样支持判断，牌与遗物怎样改变已有选择，以及这套设计对不同玩家的吸引力和负担。

本轮读取公开资料，未运行或试玩游戏；不混用二代、桌游或模组规则。开发者目标、评论者体验和下文提出的候选分析分别记录。资料中的2019年版本、销量和内容数量不能直接描述当前版本。本文不新增个人认可、实验结果或已验证的玩家效果。

## 开发者怎样解释这些取舍

### 给出能判断的眼前威胁

Anthony Giovannetti在访谈中回顾，早期敌人不预告行动，玩家难以判断该攻击还是防御；团队后来公开意图。另一份原始采访还说明，中间试过需要逐个点击敌人查看的长文字面板，最终改为头顶图标。[Hope in Source访谈](https://hopeinsource.com/games/)、[Ars Technica采访](https://arstechnica.com/video/watch/war-stories-slay-the-spire-war-stories/?c=series)

由此可以提出一个待检验的解释：把当前威胁交代清楚，可能减少无依据猜测，让有限手牌和能量更容易形成可比较的办法。公开当前行动仍然保留未来抽牌、奖励与路线的不确定性；个别敌人还会根据战场变化改变意图，不能写成全部未来都已确定。

### 让牌有用处，允许计划随局势变化

Anthony谈到不希望玩家每次都指定同一流派，要根据本局的卡牌、遗物与临近挑战调整选择。GDC讲义将平衡目标概括为卡牌有适用之处，同时避免某些内容过度左右整体选择。[Hope in Source访谈](https://hopeinsource.com/games/)、[GDC原始讲义](https://media.gdcvault.com/gdc2019/presentations/Giovannetti_Anthony_SlayTheSpire.pdf)

这两项目标相容：某张牌可以在一套牌中很强，也可以在另一局不值得拿。不能据此声称所有牌同样强、所有构筑都可通关。单人游戏允许偶尔形成很强的组合，也仍需考虑组合形成的难度以及它是否挤掉其他有意义的选择。

## 两位评论者为什么评价不同

Evan Lahti在2019年的PC Gamer评测中，用机器人牌组说明临场修正的重要性。他起初追求需要几回合启动的组合，面对开局压力时吃亏，随后把放弃不合条件的计划也视为一种技能。他的造飞机类比表达了边推进、边搭建的乐趣。[Evan Lahti评测](https://www.pcgamer.com/slay-the-spire-review/)

Brad Gallaway在同年的GameCritics评测中认可信息显示，却认为随机过重。他想尝试一套策略时，关键牌或遗物可能迟迟不来，希望对后续尝试有更多持续影响。他评的是当时Switch版本，经验和期望也与Evan不同。[Brad Gallaway评测](https://gamecritics.com/brad-gallaway/slay-the-spire-review/)

本页据此提出的区别是：希望练习临场调整的人，可能把随机看成每次不同的问题；希望指定一套组合来体验的人，可能把它看成迟迟不提供零件。两位作者没有在这些文章中彼此辩论；两份评测也不代表总体玩家调查。不能用一方的体验证明另一方不会玩，或证明随机必然好、必然坏。

## 可以迁移的候选分析与验证办法

以下是从材料形成的设计假设，尚无本轮试玩或对照实验。迁移时应保留原作与拟改游戏的差别。

| 候选分析 | 条件、反例与代价 | 可以怎样检验 |
|---|---|---|
| 公开当前威胁，可能让玩家更有依据地权衡攻击、防御与击杀 | 信息仍需容易辨认；大量数值和状态也会增加负担。未知本身服务恐怖或猜测时，不宜全部公开 | 用同一组战斗规则比较意图显示方式，记录玩家能否说明所防范的结果、是否反复查找信息，以及主观负担；不只比胜率 |
| 新奖励改变现有资源的用途，可能提供下一场立刻想试的办法 | 强组合若形成过于稳定，变化也可能变成重复执行；奖励出现不能直接证明想继续玩 | 记录获得奖励前后的计划、下一场实际使用和停止意愿，区分尝鲜、计划修正与机械重复 |
| 随机与固定规则结合，可能让旧知识在新局面中继续有用 | 喜欢指定流派或稳定表演的玩家可能受挫；不利条件仍存在，不能把所有失败归因水平 | 在同一作品中分别观察自由应变与指定组合目标的玩家，记录哪些落空是愿意接受的挑战、哪些变成无效等待；不预设指定组牌更优 |
| 长期后果能让早期决定有分量，也可能使失败难以归因 | 末回合规则透明，不保证整局因果透明；结局可能由多次决定与随机共同造成 | 失败后先让玩家自行复述原因，再用回放核对；若只记得最后一次坏抽牌，检查能否在不替玩家给答案的前提下呈现此前关键变化 |
| 风险收益跨房间发生，可能让战斗、休息与成长互相影响 | 风险是否值得取决于当下牌组、血量、资源及后续机会；不能推广为精英越多越好 | 比较同一局面下不同路线的可行计划及其代价，并观察玩家为什么选保守或冒险；纸面计算与真实体验分开报告 |

这些分析不能证明心理成瘾机制。持续游玩的行为、当时觉得好玩、愿不愿再开一局与实际长期回访应分别观察。也不能用学习留下了，抹掉一局失败已经付出的时间成本。
