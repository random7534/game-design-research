# 游戏玩法策划的逻辑地图

重点是把玩家的体验和具体行动连起来：玩家为什么行动，依据什么做选择，规则怎样回应，以及后续局势有什么变化。用连续的游玩过程检查这些关系，再以原型和真实反馈修正。下面是本库综合的玩法策划入口。

```text
玩家与游玩情境 → 具体动作与目标 → 信息、选择和规则
                                      ↓
                          反馈、结果与下一步局势
                                      ↓
                       机制组合、挑战与成长的变化
                                      ↓
                            游玩推演与原型验证
                                      ↓
                            修改玩法与范围假设

实际制作时再展开：技术实现、资产生产、设备适配与发布
```

| 设计层 | 真正要回答的问题 | 常见产物 | 何种证据有用 |
|---|---|---|---|
| 动机与动作 | 玩家在什么情境下想做什么、感到什么 | 玩法简表、具体操作 | 行为、表达、原因、继续或退出 |
| 玩法循环 | 结果怎样改变下一次行动，哪个层次需要重复 | 连续游玩过程、局内与局外关系 | 重复后发生了什么变化 |
| 决策与表达 | 信息、办法、代价和回应是否有价值 | 选择表、情境对照 | 理解、取舍、表达和策略迁移 |
| 机制与深度 | 规则怎样互相改变用途，负担是否值得 | 机制组合与多个情境 | 换局势后能否产生不同做法 |
| 数值与资源 | 成本收益怎样影响行动，转换是否失控 | 关系图、阶段与边界 | 资源循环、支配策略与实际行为 |
| 关卡与节奏 | 玩家怎样学习，挑战怎样变化和恢复 | 教学与挑战样段 | 独立运用、误解、压力与停顿 |
| 奖励与成长 | 奖励鼓励什么，新能力怎样改变旧问题 | 能力、奖励及变化示例 | 实际选择与被意外鼓励的重复 |
| 重复可玩性 | 同一规则为什么还能得到新的体验 | 不同开局或立场的过程对照 | 新策略、技术提升、创作和表达 |
| 叙事与手感 | 行动如何产生理解、情感和可感知回应 | 对话或音画交互样段 | 可读性、因果理解、时序与感受 |
| 原型验证 | 哪个玩法假设最需要证据 | 最小可玩片段与试玩记录 | 观察能否支持继续、修改或删除 |

从当前玩法问题进入，不要求依次填完每张表。创意方案要能演示玩家如何玩；已有作品优先查看实际卡点。小规模方案保留决定乐趣的规则与反馈，按本轮问题删减内容。

## 容易混在一起的概念

- 玩法循环描述玩家反复进行的行为，程序循环组织输入、模拟和绘制；两者有关但不等同。
- 平衡关注选项在具体情境中的价值，既不要求全部数字相同，也不默认削弱一切强力组合。
- 节奏是压力与信息在时间上的安排，难度涉及完成要求、风险与能力；可分别修改。
- 可玩原型检查关键假设，纵向切片检查目标质量与制作流程；切片可小，代表性不能省。
- 正确性、手感、理解与市场表现需要不同观察，不能让一种测试替代所有结论。
- 外部主张、自己的综合、项目结果和个人认可可以互有关联，保存时仍应标清身份。
