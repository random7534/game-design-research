# 关卡、谜题与探索

以下是公开资料支持的候选方法；图表与审核过程为本库综合，尚无本库玩家验证。来源及读取范围见 [sources.md](sources.md)。Outer Wilds 论文描述 2013 年学生版本，其多数知识网络尚未实现；这里只采用设计提案及早期教学观察，不声称商业成品效果。[L03]

## 五项可复用方法

### 从一次规则发现生成小关卡，再生长出变体

先记录某次操作带来的意外用途或关键推断，搭出能让玩家发现它的最小场景。发想卡至少含“玩家原先可能怎样理解”“什么观察会推翻或修正理解”“怎样检验新理解”。再试动作顺序颠倒、极端布局、接近无解的边界。意外解法先保存，检查能否成为另一道题，再决定是否封住。Patrick Traynor 的原文给出了这些实际发想入口；我们的卡片格式是对它们的操作化整理。[L01]

**适用条件：**这一流程适合以规则发现为目标的谜题。若作品承诺自由解决问题，不能为了保住作者唯一答案，把符合规则的办法逐一封死。判断重点是玩家是否理解了重要关系，以及新办法是否破坏后续内容的必要条件。

### 分别画通关依赖、知识依赖和线索联系

通关依赖写系统真正检查的条件；知识依赖写理解下一件事所需的概念；线索联系写一处发现怎样引向另一处。三者可以重合，也可能完全不同。Gilbert 的图记录解题步骤的前提，可以检查并行问题与瓶颈；Outer Wilds 论文中的线索则教玩家抵达某处的方法，获取线索本身未必是系统锁。[L02][L03]

据此对每个节点核对：先到这里的玩家知道什么；漏掉某条线索是否仍有办法；卡住后还有什么有意义的行动；离开一区后还能否取回必需物。两条线索指向同一结论，不能自动改成“必须集齐两条才准推理”。

**边界：**这三图是本次综合的分析工具，来源没有提出同名通用规范。图也不证明问题好玩；线索是否引起兴趣、推理是否成立仍需试玩。

**自拟例子，未试玩：**水阀未关闭时，安全联锁使合闸按钮无效；关闭水阀后再次合闸，温室门才能打开。过早合闸不会造成损坏，也无需复位。通关依赖是“关阀 → 成功合闸 → 开门”；知识关系是理解联锁；线索联系是检修图解释联锁、路牌指向楼上的阀门。阅读两者不构成通关标记，自行找到阀门并理解设备的玩家可以直接操作。这个例子只说明图的区别，没有给出完整关卡布局或难度结论。

### 教学应保留正式玩法中的判断用途

为每项教学写“训练中怎样使用”与“正式游玩怎样使用”，核对两者差异。Outer Wilds 早期教学要求给指定对象拍照，实际玩法却希望玩家用探测器试探未知；它还漏教了重要的飞行能力。论文报告了重做开场、采用模型飞船等训练后的改善；多项内容同时变化，不能将改善单独归因于模型训练。[L03]

可以先用安全、规模较小的场景理解关系，再让玩家在未见过的情境中独立决定何时使用。通过教程中的指定按钮，仅说明动作完成。要检验迁移，还需观察玩家能否识别适用时机、预测结果并调整办法。

**边界：**“先模型、后真实场景”是可选路径。写作中不要把这次开发者观察包装为对照实验，也不要把自由选择教学强加给必须准确掌握安全操作的所有作品。

### 将“太难”拆成可观察的失败，再改一个因素

使用如下诊断表；它是研究综合建议，无通用阈值。

| 观察 | 优先怀疑 | 下一次可比较的改动 |
|---|---|---|
| 没看见入口或可交互物 | 可见性与行动发现 | 改视觉/声音线索，保持解法 |
| 反复作出同一种错误预测 | 规则理解 | 补一个能区别两种解释的反馈 |
| 知道规则，却未形成关键关系 | 推断 | 减少无关对象，保留需发现的关系 |
| 有正确计划，中途忘记状态 | 计划与记忆负荷 | 外显已知状态或缩短无意义往返 |
| 能说出办法，动作总未被接受 | 操作执行与输入判定 | 核对输入缓冲、碰撞和容错窗口 |
| 会解，重试仍令人放弃 | 恢复代价 | 调整重置位置与重复片段 |

输入边界与容错见 [动作手感](action-feel.md)，重试负担见 [原型与失败成本](prototype-and-challenge.md)。应先查意图是否正确识别，避免仅靠放慢敌人或泄露答案来统一“降难度”。同一谜题学会后很难恢复未知状态，比较提示效果时应换等价题或新参与者；这是本次提出的验证注意事项。

### 给探索安排可以追问的问题，并区分陌生与反常

对一处发现写下：玩家此时理解的常态是什么；哪里与预期不符；他可能问什么；手头有什么可调查途径。Outer Wilds 论文记载，旧开场过早让外来物坠落，但村庄本身对玩家也同样陌生，异常没能形成预期中的牵引。[L03] 因而不能只布置“奇怪东西”，还要给玩家定位自身、认识局部环境和形成问题的机会。

开放探索宜测试不同进入顺序：每种顺序能否产生局部理解，遗漏线索后能否重新定位。线性教学可更精确控制先决知识，但也要检查一题堵住全部进展的代价。Gilbert 提供了并行问题、阶段性汇合的结构建议；其具体分支数量是个人经验，不设为检查器硬指标。[L02]

## 来源之间的张力

Gilbert 1989 年文章强调清楚的终点、先遇到问题再找解法，反对必须死亡才能学会的冒险游戏，并建议用配合玩家意图的戏剧时机。[L05] Outer Wilds 的论文则围绕逐步形成的问题、持续变化的世界和时间循环展开。[L03] 两者服务的体验不同：前者希望维持故事行动的连贯与可理解性，后者刻意让知识跨循环积累，让玩家适应无法控制的系统。

因此，“所有问题都先讲明”“世界必须等玩家”“死亡绝不能提供知识”都不能直接写成全类型规则。应检查作品向玩家许诺什么：追求首次解出的连贯叙事时，意外死亡后才得知必要信息可能破坏因果；明确以重复观察学习为结构时，重复应产生可利用的新理解，并检查重试成本。Gilbert 在 2004 年转载前言中也说明已不再同意文中所有内容，保留这层自我修正很重要。[L05]

## 一项最小审核练习

拿项目中现成的一段关卡，不增添系统，按当前问题检查：

1. 此关希望玩家发现的关系，以及一个确实可执行的解法。
2. 抵达、理解、完成所需前提；标明系统条件、知识前提、可选提示。
3. 一名新玩家的停顿、预测、尝试、反馈；按上表定位下一次改动。

没有真实参与者时，第三项应写“待试玩”，先做规则推演，不能以助手自己知道答案后的顺利操作代替新手理解。
